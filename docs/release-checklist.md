# Release checklist

Use this checklist before tagging and publishing an MVP release of `ai-project-docs`.

---

## Build and tests

- [ ] `npm install` completes without errors
- [ ] `npm run build` compiles TypeScript with zero errors
- [ ] `npm test` passes all unit tests (including `src/config/config.test.ts`)
- [ ] `npm run smoke` passes — config error cases (exit `1`) and happy path (exit `0`)

---

## Documentation

- [ ] `README.md` — quick start, CLI reference, exit codes, output structure, limitations
- [ ] `AGENTS.md` — safety constraints, PKM rules, exit code table
- [ ] `docs/architecture.md` accurate if pipeline or layers changed
- [ ] `docs/folder-structure.md` accurate if folders were added or renamed

---

## Generated output inspection

Run against this repository:

```bash
npm run build
node dist/cli.js .
```

Verify:

- [ ] `.ai-docs/knowledge/project-knowledge.json` exists and parses as valid JSON with `metadata` and `repository` sections
- [ ] Key Markdown files exist: `architecture.md`, `agent-navigation.md`, `folder-structure.md`
- [ ] Generated files carry the marker: `<!-- Generated by AI Project Docs. Safe to update. -->`
- [ ] Run summary shows `Validation: Status: passed`
- [ ] User-managed files without the marker were not overwritten

---

## Package metadata

- [ ] `name`, `version`, `description`, `license`, `author` are correct
- [ ] `repository`, `bugs`, `homepage` point to GitHub
- [ ] `bin.ai-project-docs` → `./dist/cli.js`
- [ ] `files` whitelist: `dist`, `README.md`, `LICENSE`, `AGENTS.md`
- [ ] `engines.node` is `>=18.0.0`
- [ ] `prepublishOnly` runs `npm run build`
- [ ] `LICENSE` matches the `license` field (MIT)

---

## CLI behavior

| Scenario | Expected exit |
|---|---|
| No arguments | `1` |
| `--help` / `-h` | `0` |
| Non-existent path | `1` |
| File (not directory) as target | `1` |
| Empty or whitespace `--docs-dir` | `1` |
| `--docs-dir` set to `.` | `1` |
| `--docs-dir` with path separators or `..` | `1` |
| `--help` combined with other arguments | `1` |
| Unknown flag | `1` |
| Flag without value | `1` |
| Successful run | `0` |
| Validation failure | `2` |
| Pipeline runtime failure | `3` |

---

## Known limitations documented

- [ ] OpenRouter not required for MVP
- [ ] Source code never modified
- [ ] Markdown generated from PKM
- [ ] MVP limitations and roadmap listed in README
- [ ] Skipped AI steps (`○`) explained as placeholders, not failures

---

## Pre-publish dry run

```bash
npm run build
npm pack --dry-run
```

Confirm tarball contains only whitelisted files and `dist/cli.js` is present.

---

## Post-release

- [ ] Git tag created
- [ ] Published to npm (if applicable)
- [ ] `npx ai-project-docs --help` works from the published package
